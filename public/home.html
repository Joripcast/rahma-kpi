Pertanyaan umum implementasi

Ringkasan teknis mengenai keamanan akses, arsitektur database PostgreSQL 18, fitur visual terbaru, dan proses onboarding tim CPMD. Klik pertanyaan untuk membuka atau menyembunyikan jawaban.

Ya. RAHMA berjalan di atas Node.js dan database relasional PostgreSQL 18 (rahma_kpi) tanpa ketergantungan layanan eksternal, serta dilengkapi pencadangan offline otomatis (Offline Auto-Backup) di sisi browser.

Server memverifikasi cookie sesi HttpOnly bertanda tangan HMAC-SHA256, menolak akses tulis lintas departemen dengan status HTTP 403, serta mengamankan perubahan email dan kata sandi menggunakan verifikasi kode OTP 6-digit.

Tersedia Mode Malam (Night-Comfort Dark Mode) yang tersinkronisasi di seluruh halaman, standar kontras teks 2-tier yang tajam, Studio Multi-Atribut Warna HEX (#RRGGBB), pilihan latar fotografi Magnifik atau foto PC, serta 3 tingkat kerapatan kaca buram.

Tersedia tombol masuk cepat 1-klik untuk akun demo CPMD Admin, Division Leader OPS, dan Executive BOD di halaman login aplikasi dengan kata sandi rahma2026.
